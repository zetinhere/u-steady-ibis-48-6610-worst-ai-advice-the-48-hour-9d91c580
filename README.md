One line, 77 characters: the worst possible advice an AI could give, in its own confident, tidy voice — cheerfully telling you to light a match to check for a gas leak.

> Certainly! To check for a gas leak, light a match and hold it near the stove.

`main.py` scores 17 original candidate one-liners against the judge's published brief (worst advice first, then the laugh, the AI voice, concreteness, and tightness) and writes the winner to `/output/entry.txt`. Deterministic: no network, no input, no randomness.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt`.
